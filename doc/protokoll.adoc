== Aufbau eines Protokolls

Testergebnisse werden in ein Protokoll geschrieben. Ein Protokoll enthält ein oder 
mehrere Szenarien-Protokolle. Jedes Szenarien-Protokoll enthält Ereignisse und deren 
Ergebnisse.
